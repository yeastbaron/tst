# **App Name**: SalleDeVente.sn

## Core Features:

- Marketplace Navigation: Exhaustive categorization and sub-categorization of items (New and Used) with an optimized layout for high-speed browsing.
- Smart Visual Search Tool: A semantic search tool powered by generative AI that understands natural language queries to find relevant products even with typos or descriptive language.
- Auto-Margin Listing Engine: Simplified listing process where users upload up to 10 photos and a price; the platform automatically adds a 10% commission to the final buyer price.
- One-Tap Google Authentication: Frictionless login using Google accounts to bypass traditional sign-up forms, suitable for users prioritizing speed and simplicity.
- Confidential Seller Transactions: Identity protection system that hides seller details from buyers to prevent direct bypass and ensures the admin manages all transactions.
- Unified Order Management: Real-time notification system for Admin and Sellers when an order is placed, supporting both online payment and cash on delivery.
- Admin Moderation Hub: Tools for administrators to feature products on the homepage and manage user access, including banning for TOS violations.

## Style Guidelines:

- Main font: 'Oxanium' (sans-serif), a technical and geometric font requested for its distinct modern character. Note: currently only Google Fonts are supported.
- Background: Clean and luminous Pure White (#FFFFFF) to ensure maximum clarity and a premium feel.
- Primary Color: Deep Cobalt (#2E5BFF) representing trust and the coastal vitality of Dakar, ensuring strong visibility on white backgrounds.
- Accent Color: Vibrant Marigold (#FFB800) used for high-contrast 'Buy' buttons and call-to-actions, facilitating easy interaction for all literacy levels.
- High-fluidity mobile-first design focusing on large touch targets, intuitive swiping through product galleries, and minimal clutter.
- Explicit, bold line-art icons used to assist navigation for less-schooled users, reducing reliance on text comprehension.
- Smooth micro-interactions and transitions to provide feedback during filtering, sorting, and image loading, creating a modern application feel.
