# Build Project Workflow

This workflow describes the step-by-step process of installing and building the `SalleDeVente.sn` Next.js application.

## Prerequisites

- **Node.js**: Ensure Node.js v20+ (recommended v22+) is installed.
- **Project Folder**: You should be in the root directory of the project.

## Step 1: Install Dependencies

To install the necessary project dependencies (including Genkit, Firebase SDKs, UI components, etc.), run:

```bash
npm install
```

## Step 2: Build the Project

To compile and build the production bundle of the Next.js application, run:

```bash
npm run build
```

This will run the Next.js compiler and bundle all resources for production deployment.
